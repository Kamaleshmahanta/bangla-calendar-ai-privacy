১. ভূমিকা

Bangla Calendar AI Powered ব্যবহারকারীর গোপনীয়তাকে গুরুত্ব দেয়। এই গোপনীয়তা নীতিতে অ্যাপটি কোন permission বা তথ্য ব্যবহার করে, সেই তথ্য কী উদ্দেশ্যে ব্যবহার করা হয় এবং বর্তমান implementation অনুযায়ী তথ্য কীভাবে সংরক্ষণ ও পরিচালনা করা হয় তা ব্যাখ্যা করা হয়েছে।

২. আমরা কোন তথ্য ও Permission ব্যবহার করি

অ্যাপের নির্দিষ্ট feature ব্যবহার করার জন্য কিছু Android permission প্রয়োজন হতে পারে। বর্তমান সংস্করণে মূলত Location, Microphone এবং Notification permission ব্যবহৃত হয়।

Permission শুধুমাত্র সংশ্লিষ্ট feature চালানোর জন্য ব্যবহার করা হয়।

৩. Location তথ্য

Sunrise/Sunset এবং Moonrise/Moonset হিসাব করার জন্য অ্যাপ approximate অথবা precise location ব্যবহার করতে পারে।

অ্যাপটি Android device-এর available current বা last known location ব্যবহার করে স্থানীয়ভাবে এই হিসাব সম্পন্ন করে।

বর্তমান implementation অনুযায়ী অ্যাপ background location tracking করে না এবং location তথ্য developer-operated server-এ পাঠানোর কোনো app-owned ব্যবস্থা পাওয়া যায়নি।

৪. Microphone / Voice Input

Voice Input feature ব্যবহার করার সময় অ্যাপ Microphone permission চাইতে পারে।

বর্তমান implementation অনুযায়ী অ্যাপ নিজে microphone audio developer server-এ upload বা permanently store করে না।

Voice recognition Android-এর speech recognition service-এর মাধ্যমে পরিচালিত হতে পারে। ব্যবহৃত device, Android version এবং speech recognition provider-এর উপর নির্ভর করে voice data সংশ্লিষ্ট provider দ্বারা process হতে পারে।

সেই processing সংশ্লিষ্ট provider-এর নিজস্ব privacy policy এবং device settings-এর অধীন হতে পারে।

৫. Notifications

অ্যাপ ব্যবহারকারীকে দৈনিক পঞ্জিকা সম্পর্কিত notification দেখানোর জন্য Notification permission ব্যবহার করতে পারে।

ব্যবহারকারী Android system settings থেকে notification permission পরিবর্তন বা বন্ধ করতে পারেন।

৬. Local Data Storage

Daily Notebook feature-এর মাধ্যমে তৈরি user entry বা note ব্যবহারকারীর device-এর app storage-এ local ভাবে সংরক্ষিত হয়।

Daily Notebook data-এর মধ্যে ব্যবহারকারীর দেওয়া title, details, category, amount এবং সংশ্লিষ্ট date/time information থাকতে পারে।

বর্তমান implementation অনুযায়ী এই Daily Notebook records developer-operated server-এ পাঠানোর কোনো app-owned ব্যবস্থা নেই।

Daily Notebook-এর local SharedPreferences data Android cloud backup, device-transfer এবং legacy Android Auto Backup থেকে exclude করা হয়েছে।

৭. Legacy Baki/Dhar Data

পুরোনো app version-এ Baki/Dhar Khata ব্যবহার করা হয়ে থাকলে সেই পুরোনো local data app update করার পরও device-এর app storage-এ থেকে যেতে পারে।

বর্তমান app version-এ Baki/Dhar Khata user-facing feature হিসেবে উপলব্ধ নয়।

এই legacy data-তে পুরোনো version থেকে person name, mobile number, amount, reason, status এবং date/time সম্পর্কিত তথ্য থেকে থাকতে পারে।

বর্তমান implementation অনুযায়ী এই legacy records developer-operated server-এ পাঠানোর কোনো app-owned ব্যবস্থা নেই।

Legacy Baki/Dhar SharedPreferences data Android cloud backup, device-transfer এবং legacy Android Auto Backup থেকে exclude করা হয়েছে।

Android system settings থেকে app data clear করা অথবা app uninstall করলে এই local legacy data remove হতে পারে।

৮. AI Panjika Search

বর্তমান AI Panjika Search এবং সংশ্লিষ্ট search functionality local/offline app data ব্যবহার করে।

বর্তমান implementation-এ remote AI API, cloud backend অথবা developer-operated online server-এর মাধ্যমে search query পাঠানোর ব্যবস্থা পাওয়া যায়নি।

৯. Internet / Server Transmission

বর্তমান app version-এ Android INTERNET permission declared নেই।

বর্তমান audited implementation অনুযায়ী Daily Notebook, AI Panjika Search data অথবা location information developer-operated server-এ পাঠানোর কোনো app-owned ব্যবস্থা পাওয়া যায়নি।

পুরোনো version থেকে device-এ থেকে যাওয়া legacy Baki/Dhar data-ও বর্তমান app-owned code দ্বারা developer-operated server-এ পাঠানো হয় না।

১০. বিজ্ঞাপন ও Analytics

বর্তমান app version-এ advertising SDK, analytics SDK, advertising ID usage অথবা third-party crash-reporting SDK পাওয়া যায়নি।

ভবিষ্যতে এই behavior পরিবর্তিত হলে এই Privacy Policy প্রয়োজন অনুযায়ী update করা হবে।

১১. Data Sharing

বর্তমান implementation অনুযায়ী অ্যাপ ব্যবহারকারীর locally stored Daily Notebook records developer-operated server, advertising service অথবা analytics service-এর সঙ্গে share করে না।

বর্তমান version-এ legacy Baki/Dhar local records-এর জন্যও developer-operated server sharing path পাওয়া যায়নি।

তবে Voice Input ব্যবহার করলে Android speech recognition provider voice input process করতে পারে। সেই processing অ্যাপ developer-এর direct server processing নয় এবং সংশ্লিষ্ট provider/device configuration-এর উপর নির্ভর করে।

১২. নিরাপদ Data Handling

অ্যাপটি permission শুধুমাত্র সংশ্লিষ্ট feature চালানোর জন্য ব্যবহার করে।

Daily Notebook data device-এর app storage-এ local ভাবে থাকে। Android system app storage এবং device security settings এই local data-এর access নিয়ন্ত্রণ করে।

Daily Notebook local data Android cloud backup, device-transfer এবং legacy Android Auto Backup থেকে exclude করা হয়েছে।

পুরোনো version থেকে থেকে যাওয়া legacy Baki/Dhar local data-ও Android cloud backup, device-transfer এবং legacy Android Auto Backup থেকে exclude করা হয়েছে।

Current implementation অনুযায়ী অ্যাপ এই Daily Notebook অথবা legacy Baki/Dhar records developer-operated server-এ পাঠায় না।

এই Privacy Policy encryption, end-to-end encryption অথবা custom cryptographic storage-এর কোনো unsupported দাবি করে না।

১৩. Data Retention এবং Deletion

Daily Notebook data ব্যবহারকারীর device-এর app storage-এ থাকে যতক্ষণ না ব্যবহারকারী app-এর available edit/delete functionality ব্যবহার করে সংশ্লিষ্ট entry পরিবর্তন বা delete করেন।

Android system settings থেকে app data clear করা অথবা app uninstall করার মাধ্যমেও Daily Notebook-এর local data remove হতে পারে।

বর্তমান app version-এ Baki/Dhar Khata user-facing feature উপলব্ধ নয়। তাই legacy Baki/Dhar data-এর জন্য কোনো current in-app Baki/Dhar edit/delete functionality দাবি করা হচ্ছে না।

পুরোনো version থেকে legacy Baki/Dhar local data থেকে থাকলে Android system settings থেকে app data clear করা অথবা app uninstall করার মাধ্যমে সেই local data remove হতে পারে।

App uninstall করলে Android সাধারণত app-এর local storage-এর সঙ্গে সংরক্ষিত data remove করে।
